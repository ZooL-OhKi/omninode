# Browser native integration

Extension 0.2.0 loads service_worker.js, native_client.js and desktop_broker.js. Permissions are activeTab, tabs and nativeMessaging. No HTTP host permissions, clipboard permission, token storage, or automatic chat content scripts are enabled in this manifest. Legacy files remain in the repository for review and tests, but the old HTTP worker and Gemini content adapter are not loaded. This intentionally disables the previous unsafe automatic file-write path.

The toolbar popup is an accessory for selecting the active AI tab, requesting native local consent, STOP, screenshot preview and opening Gemini/Claude/Perplexity helper tabs in the controller window. Only the extension popup may invoke these operations; web pages and content scripts are rejected. Navigation or closure of the controller tab revokes its native session. Helper tab creation is not AI collaboration, reading or sending messages.

Executed in assistant environment: 15 new broker unit tests passed with fake Chrome/native APIs; syntax checks passed. A real isolated Chromium profile loaded the extension 0.2.0, started the service worker, loaded both native classes, attempted connectNative, and correctly rejected the absent native host with 'Specified native messaging host not found.' No physical desktop input, native Windows launch, real account login or popup consent workflow was exercised. CI now discovers all extension test files.

Not yet complete: native host installer/registration, native screenshots over the 1 MiB limit, direct assistant operation requests from the authorized chat, automatic screenshot/result attachment, robust streaming completion, Unicode typing, split-view UI and multi-AI coordination. Native STOP/corner fail-safe cannot undo delivered input. The browser badge can be stale after a local host stop until the next response/disconnect. No local copy update, host installation, deployment or merge was performed by this commit. The current web chat still cannot operate the desktop through this popup-only integration.
